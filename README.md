# Minecart (Quartz Crystal Calculator)

Minecart is a lightweight, single-page calculator that helps players estimate crystal sales and combo bonuses for the board game Quartz. It runs fully in the browser with no build step.

## Features

- Crystal quantity inputs with quick stepper controls.
- Automatic best-combo recommendation and manual combo selection.
- Base total vs. combo total comparison.
- Daily earnings log with a summary after multiple days.
- Persistent state stored locally in the browser.

## Tech Stack

- HTML, CSS, and vanilla JavaScript.
- Google Fonts (Caesar Dressing).
- LocalStorage for persistence.

## Getting Started

1. Clone or download this repository.
2. Open `index.html` in your browser.

No dependencies or build tools are required.

## Usage

1. Enter the quantity of each crystal you plan to sell.
2. Review the recommended combo or pick a different combo manually.
3. Check totals and details to understand the calculation.
4. Optionally save the day's earnings to track multiple days.

## Data & Privacy

All data is stored locally in your browser using `localStorage`. No data is sent to any server.
