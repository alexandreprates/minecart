# Minecart

Minecart é uma calculadora leve de página única que ajuda jogadores a estimar vendas de cristais, bônus de combo e a pontuação final de uma partida de Quartz. Ela roda totalmente no navegador, sem etapa de build.

## Recursos

- Entrada de quantidades com controles rápidos de incremento e decremento.
- Recomendação automática do melhor combo e seleção manual de combos.
- Comparação entre total base e total com combo.
- Registro de faturamento diário com resumo da partida após o 5º dia.
- Campo para informar a soma das cartas e calcular a pontuação final.
- Estado persistido localmente no navegador.

## Tecnologias

- HTML, CSS e JavaScript puro.
- Google Fonts (Caesar Dressing).
- `localStorage` para persistência.

## Como usar

1. Clone ou baixe este repositório.
2. Abra `index.html` no navegador.

Nenhuma dependência ou ferramenta de build é necessária.

## Versão publicada

## Fluxo de uso

1. Informe a quantidade de cada cristal que pretende vender no dia.
2. Revise o melhor combo sugerido ou selecione outro manualmente.
3. Confira os totais e os detalhes do cálculo.
4. Salve o faturamento de cada dia.
5. Após o 5º dia, informe a soma das cartas para obter a pontuação final da partida.

## Dados e privacidade

Todos os dados são armazenados localmente no navegador usando `localStorage`. Nenhuma informação é enviada para servidor.
